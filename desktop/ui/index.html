nn-anime no pudo arrancar el servidor

Esta ventana es la aplicación, pero el servidor local que vive detrás no llegó a arrancar, así que no hay interfaz que enseñar. El motivo completo está en el registro:

  • %LOCALAPPDATA%\nn-anime\cache\desktop.log en Windows
  • ~/.cache/nn-anime/desktop.log en Linux y macOS

Lo más habitual es que falte el servidor: el ejecutable nn-anime tiene que estar en la misma carpeta que este programa, porque el anfitrión lo lanza como hermano. Desde una terminal, nn-anime --no-open dice el motivo ahí mismo.
