## T164g — La visibilidad se mide sobre la ventana de la aplicación (**tarea insertada**)

**Estado:** hecho.

**Commit:** `fix(package): la visibilidad se mide sobre la ventana de la aplicación (T164g)`.

**Por qué se inserta:** el run `40058651658` pasó la cadena entera —ventana, servidor extraído en
`%LOCALAPPDATA%\nn-anime\bin\0.1.0`, loopback— y falló en la última comprobación: «la ventana sigue
visible después de cerrarla». La comprobación volvía a preguntar `MainWindowHandle` **después** de
cerrar; el proceso tiene más de una ventana (la de la bandeja), y el handle podía ser el de otra.

**Qué entra:**

  `IsWindowVisible` sobre ese handle después de la X. El error dice el título que quedó.
- Guarda en `scripts/desktop.test.ts`.

**Verificación en esta máquina:** `bun test scripts/desktop.test.ts` **47 pasan** · `.ps1` parsea sin
errores · `bun run typecheck` 0 · `bun run lint` 0.

**Lo que NO está verificado:** que el handle guardado sea el que Windows oculta al pulsar la X. Lo
mide el siguiente run; si sigue visible, el problema es del `hide()` del anfitrión y no de la prueba.
