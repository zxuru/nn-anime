## T183b — la descarga directa con reanudación (roadmap 1.3b)

**Estado:** hecho.

**Commit:** `feat(media-proxy): la descarga directa con reanudación (T183b)`.

**Verificación:** `bun run typecheck` 0 · `bun run lint` 0 errores (27 avisos anteriores) ·
`bun test packages/media-proxy` **248 pasan, 0 fallan** (7 nuevas).

**Medido mutando:** sin el `Range` no se reanuda y vuelve a bajar el archivo entero; sin tirar el
temporal cuando el servidor contesta 200 a un rango, el archivo queda con el principio duplicado;
sin el tope, un cuerpo enorme se escribe hasta llenar el disco; sin comprobar el total, una descarga
cortada se renombra como completa.

**Nota:** `downloadFile` escribe en `.part`, reanuda con `Range`, descarta el temporal si el
servidor ignora el rango, se detiene en `416` cuando ya estaba completo, deja el `.part` ante un
fallo para reintentar y renombra al terminar. No decide rutas ni hosts: eso es T183d. Un fallo de
red o un `500` no borra lo descargado.
