## T248 — el gancho `pre-commit` no moría por falta de `.tmp/`

**Estado:** hecho.

**Commit:** `fix(repo): el gancho crea su temporal aunque `.tmp/` no exista (T248)`.

**Verificación:** `bun run typecheck` 0 errores · `bun run lint` 0 errores (37 avisos y 1 info, los de
la línea base) · `bun test scripts/git-hooks.test.ts` **12 pasan, 0 fallan**.

**El defecto:** el gancho captura la salida de `git` en un archivo dentro de `.tmp/`, y
`mkdtempSync` **no crea el padre**. En un clon recién hecho —o en un worktree recién abierto, que es
justo cuando se abre uno para trabajar— `.tmp/` no existía, el gancho moría con un `ENOENT` **antes
de mirar el commit**, y el commit se caía con un error que no hablaba del gancho. Pasó de verdad en
esta sesión: dos commits se cayeron con «ENOENT: no such file or directory, mkdtemp
'…\.worktrees\T233\.tmp\hook-git-XXXXXX'» y hubo que crear el directorio a mano para poder seguir.

**El arreglo:** `scripts/git-hooks.ts` crea `.tmp/` antes del `mkdtemp`, como ya hacía
`scripts/agente.ts` desde la T223.

**Medido con mutación de la implementación, como pide el listón:** con el `mkdirSync` quitado, la
prueba nueva —«el temporal se crea aunque `.tmp/` no exista»— **falla**; restaurado, **pasa**.

**Nota:** esta tarea no estaba en `tasks/deuda.md`: salió del fallo que se vio al abrir un worktree.
