## T142 — las claves nativas separan Naruto de Shippuuden

**Estado:** hecho.

**Commit:** `fix(core): conservar Unicode en claves de título (T142)`.

**Verificación:** `bun run typecheck` · `bun run lint` (3 avisos preexistentes fuera de los archivos tocados) · `bun test packages/core` 355 pasan · `bun test packages/server` 608 pasan · `bun test packages/catalog-store` 246 pasan · Biome sobre los tres archivos de código sin errores. Regresión HTTP: falla con el `titleKey` original y pasa corregida; revertir la corrección reproduce la asignación incorrecta de la referencia local a Naruto: Shippuuden.
