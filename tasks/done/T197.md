## T197 — la 0.5.0 no se publicaba: el updater sin clave y el instalador sin probar

**Estado:** hecho.

**Commit:** `fix(release): la clave del updater y la carpeta del instalador dejan publicar (T197)`.

**Verificación:**

- **La causa del run 40828849714**: el paso «Armar el instalador (Windows) y subirlo» murió con
  `failed to decode secret key: incorrect updater private key password: Missing comment in secret
  key`. El repositorio no tenía **ningún** secreto (`total_count: 0`), así que
  `TAURI_SIGNING_PRIVATE_KEY` llegaba vacío y `tauri build` no podía firmar los artefactos de
  `createUpdaterArtifacts`. Ninguna release anterior llevaba `latest.json` ni un `.sig`: el updater
  nunca se había ejercitado.
- Clave nueva con `bun tauri signer generate` (contraseña aleatoria de 64 caracteres). La pública
  va en `desktop/src-tauri/tauri.conf.json` y se comprobó que el valor pegado es **exactamente** el
  `.pub` que escribió el generador, y que decodifica a un `minisign public key`.
  `bun tauri signer sign` con la privada produce `.sig`, y el id de clave de la firma coincide con el
  de la pública: el par es coherente.
- Secretos `TAURI_SIGNING_PRIVATE_KEY` y `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` puestos en el
  repositorio; `gh api repos/…/actions/secrets` los lista con la hora del cambio.
- `packaging/windows/probar-instalador.ps1:336` tenía `$destino:` dentro de una cadena, que
  PowerShell lee como variable con ámbito: `Variable reference is not valid`. Ahora es `${destino}`.
  Medido con el parser: el archivo da **0 errores**; mutando la línea a `$destino:` da **1 error**,
  el mismo texto que el CI. Es el fallo que esperaba detrás del de la clave, en el paso «Probar el
  instalador (Windows)».
- `bun test ./scripts/desktop.test.ts`: **47 pasan, 0 fallan**.
- `bun run lint`: verde (505 archivos).

**Nota:** `bun run typecheck` no se pudo ejecutar en el worktree: el sandbox no deja crear los
enlaces de `bun install` (`failed to symlink dependencies`), así que `tsc` no resuelve `hono` y los
demás paquetes. No se tocó una línea de TypeScript: los dos archivos del commit son un JSON de Tauri
y un `.ps1`. La clave privada vive fuera del repositorio (`~/.tauri/nn-anime.key`, con su contraseña
al lado) y hay que guardarla: sin ella no se pueden firmar actualizaciones para quien ya tenga la
aplicación instalada.
