## T164f — La prueba del instalador espera la extracción (**tarea insertada**)

**Estado:** hecho.

**Commit:** `fix(package): la prueba del instalador espera la extracción (T164f)`.

**Por qué se inserta:** el host del run `40057343237` medía **105 MB** (lleva los 98 MB del servidor
dentro), la ventana se abría y a los 0,5 s la prueba contaba **cero** procesos `nn-anime`. La causa no
era el empaquetado: el `.exe` único todavía estaba extrayendo el servidor. El `MainWindowHandle` que
la prueba tomaba como «ventana abierta» era el de la bandeja, no el de la aplicación.

**Qué entra:**
- `probar-instalador.ps1` espera a **las dos** cosas en el mismo bucle: un proceso `nn-anime` y una
  ventana. Antes rompía al primer handle y consultaba el servidor demasiado pronto.
- Si el servidor no aparece, el error sigue volcando `desktop.log` y los ejecutables de `bin`.
- El mensaje de éxito dice el título de la ventana.
- Guarda en `scripts/desktop.test.ts` para la condición doble.

**Verificación en esta máquina:** `bun test scripts/desktop.test.ts` **47 pasan** · `.ps1` parsea sin
errores · `bun run typecheck` 0 · `bun run lint` 0.

**Lo que NO está verificado:** que el instalador de Windows pase de verdad. Lo mide el siguiente run;
si vuelve a fallar, el volcado dice si es extracción, arranque del servidor o ventana.
