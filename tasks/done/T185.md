**Estado:** hecho.

**Commit:** `feat(web): la copia local manda en el reproductor (T185)`.

**Verificación:** `bun run typecheck` 0 · `bun run lint` 0 errores (28 avisos anteriores) ·
`bun test packages/web/src` **867 pasan, 0 fallan** · `bun run e2e` **111 pasan, 0 fallan**,
incluida la que comprueba que no se pide el stream.

**Medido mutando:** sin la búsqueda de la copia local, el e2e del reproductor pediría
`/api/stream/resolve` y el vídeo no saldría del archivo descargado; sin el 409/playlist de segmentos,
la descarga sin ffmpeg no se podría abrir; sin la comprobación de nombre del segmento, `../` saldría
de la carpeta.

**Nota:** el reproductor consulta `/api/downloads` antes de resolver y, si hay una fila completa del
mismo proveedor y episodio, usa `/api/downloads/:id/file`: un MP4 directo o la playlist local de
segmentos. La playlist se reescribe con rutas `/api/downloads/:id/segment/:name`, y los segmentos se
sirven sólo si el nombre tiene la forma que genera el motor. La copia local se usa **sólo en modo
`sub`**: la fila no guarda el modo, y servir un sub cuando se pidió dub sería peor que volver a la
red. El e2e de la página intercepta la lista y prohíbe el stream: mide la preferencia, no una
descarga real.
