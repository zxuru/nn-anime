## T183c — HLS a disco, playlist local y remux (roadmap 1.3c)

**Estado:** hecho.

**Commit:** `feat(media-proxy): el HLS a disco y el remux opcional (T183c)`.

**Verificación:** `bun run typecheck` 0 · `bun run lint` 0 errores (27 avisos anteriores) ·
`bun test packages/media-proxy` **253 pasan, 0 fallan** (5 nuevas).

**Medido mutando:** sin elegir la variante de más ancho de banda se baja la de menos; sin reescribir
las URIs la playlist local apunta al upstream; sin `#EXT-X-ENDLIST` el reproductor no sabe que
terminó; sin rechazar `#EXT-X-KEY` se bajan segmentos cifrados que no se pueden reproducir.

**Nota:** el master se resuelve a la variante de más `BANDWIDTH`; los segmentos y el
`#EXT-X-MAP` se bajan con `downloadFile` (reanudables, `.part`), la playlist local usa nombres
relativos y no queda ninguna URL del upstream. Con `remux` inyectado se produce el MP4 y se borran
los segmentos; si el remux falla, los segmentos se quedan para reintentar. El HLS cifrado se
rechaza con el motivo. La detección real de ffmpeg y la comprobación de hosts van en T183d.
