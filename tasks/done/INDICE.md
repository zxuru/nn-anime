# Índice de fragmentos de cierre

Un fragmento de `tasks/done/` es la nota de cierre de una tarea: qué se hizo, con qué commit y con
qué medición. El integrador lo indexa aquí y retira el archivo en el mismo commit, porque un
directorio que crece sin índice deja de ser una bandeja y se convierte en un archivo muerto.

Este índice guarda lo que sirve para volver: el asunto, el commit y la verificación. **El contenido
completo de los fragmentos retirados está en la historia de git**, no hace falta otra copia:

```bash
# dónde se retiró un fragmento
git log --diff-filter=D --format=%H -- tasks/done/T56.md
# y su contenido, en el commit anterior a la retirada
git show <commit>^:tasks/done/T56.md
```

quedan identificadas aquí. **214 fragmentos indexados**; 182 se identifican
sólo en este índice y su contenido vive en la historia.
