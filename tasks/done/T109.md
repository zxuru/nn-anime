## T109 — `web`: el renglón sin nombre de episodio lleva el del título

**Estado:** hecho.

**Commit:** `feat(web): el renglon sin nombre de episodio lleva el del titulo (T109)`.

**Qué toca:** `packages/web/src/features/player/WatchEpisodes.tsx`,
`packages/web/src/features/player/WatchPage.tsx` y
`packages/web/src/features/player/WatchEpisodes.test.tsx` (nuevo).

**Lo que se veía, medido en la base real:** el usuario manda el pantallazo de la columna «EPISODIOS»
del reproductor con diez renglones que son sólo el número. No es un fallo del plugin: en
`%LOCALAPPDATA%\nn-anime\nn-anime.db`, el título `animeav1/sousou-no-frieren-2nd-season` tiene sus
diez episodios con `title` nulo.

```
sqlite> select number, title from episode where anime_id = 7 order by number;
1|null  2|null  3|null  4|null  5|null  6|null  7|null  8|null  9|null  10|null
```

**El cambio:** el renglón —que era una función interna del componente, imposible de medir con el
renderizado de servidor porque los episodios llegan por efecto— pasa a ser `EpisodeRow`, y toma el
nombre del título como respaldo cuando el episodio no trae el suyo. `WatchPage` le pasa el
`tituloAnime` que ya tenía para el encabezado y la pestaña. El nombre en blanco se trata como
ausente —un `<span>` vacío deja el hueco dentro del enlace—, y el nombre accesible lleva el mismo
respaldo que se ve: el texto visible empieza por un número suelto y «1» no dice nada.

Un proveedor que **sí** nombra sus episodios no cambia nada: manda el suyo. El del fixture es
`Episodio N`, así que el nombre accesible sigue siendo `Episodio N` y ningún caso del e2e se mueve
—`getByRole('link', { name: 'Episodio 5' })` busca por subcadena—.

**Verificación:** `bun test` en el worktree **2261 pasan, 10 fallan**, y las 10 son del arnés de git
(`scripts/agente.test.ts`, `.githooks`): `EPERM: operation not permitted, uv_spawn 'git'`, el límite
del sandbox para un proceso que captura la salida de `git` por tubería. En `main`, el mismo comando
da **2253 pasan, 10 fallan**: la diferencia es exactamente los 8 casos nuevos. `bun run typecheck` 0 ·
`bun run lint` 0 errores y los 2 avisos de siempre (`shell.css`, especificidad).

Las pruebas se escribieron **antes** del cambio y fallaron (`Export named 'EpisodeRow' not found`),
y se midieron mutando:

| Mutación | Resultado |
|---|---|
| el respaldo devuelve nada (`return undefined`) | fallan 2: el renglón sin nombre y su nombre accesible |
| el nombre del título no se recorta | falla 1: el nombre en blanco se pinta |
| se ignora el nombre del episodio | fallan 2: manda el del episodio, y su nombre accesible |
| `props.current` sin pintar el actual | falla 1: la marca del que se está viendo |

**Nota:** no hay captura de la pantalla con el cambio. El arnés de Playwright no tiene navegador en
esta máquina (`.tmp/` no tiene `ms-playwright` y `%LOCALAPPDATA%\ms-playwright` no existe), y
`bun run e2e:install` baja Chromium: se deja a quien mire la pantalla. La lista se puede ver con el
proveedor real en `animeav1` —los diez renglones de *Sousou no Frieren 2nd Season*— sin más que
abrir el reproductor de cualquiera de sus episodios.

**Nota de entorno:** `bun run scripts/agente.ts abrir` no puede lanzar `git` dentro del sandbox, así
que el worktree, la rama y el reclamo `refs/claims/T109` se crearon con los mismos tres comandos
—`rev-parse`, `update-ref`, `worktree add`— desde pwsh.
