## T167 — la X del instalador se prueba sobre la ventana que se mide

**Estado:** hecho.

**Commit:** `fix(package): la X del instalador se manda a la ventana medida (T167)`.

**Verificación:** el script parsea sin errores (`[System.Management.Automation.Language.Parser]::ParseFile`)
y `git diff --check` sale limpio. La prueba de humo del instalador de Windows falló tres veces
seguidas en el run `40127329337` con «la X cerró la aplicación: se esperaba que la ocultara en la
bandeja». El test usaba `$anfitrion.CloseMainWindow()`, que manda la X a `MainWindowHandle`; después
de crear el icono de la bandeja, ese handle puede pasar a otra ventana del proceso. Ahora se manda
`WM_CLOSE` con `PostMessage` al `$handleVentana` que se capturó al abrir la ventana y que luego se
consulta con `IsWindowVisible`, así que la prueba mide la ventana de la aplicación y no la del
icono.

**Nota:** sólo se toca la prueba; el comportamiento del anfitrión no cambia. Si la prueba sigue
fallando con el `WM_CLOSE` directo, el fallo estaría en el anfitrión y no en la prueba, y habría que
mirar el manejador de `CloseRequested` con el log del run. El tag `v0.2.0` se mueve a este commit
para que el workflow de la release use el script corregido y pueda publicar.
